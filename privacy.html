PRIVACY POLICY

隐私政策

说明 CloudBot Archive 如何访问、使用、保存及处理数据。

生效及更新日期：2026-11-14

适用范围

本政策适用于由 YarrowHH 维护的 CloudBot Archive 归档连接组件及本说明网站。当前组件仅供账户所有者自用，功能限于授权、目录检查和测试文件上传回读；不代表整个 CloudBot 项目或其他模型服务的隐私政策。

1. 请求哪些权限

应用仅请求 https://www.googleapis.com/auth/drive.file，用于访问通过应用获得授权的文件及应用创建的文件。不申请整个 Google Drive 的广泛访问权限，也不申请 Gmail、联系人或日历权限。

授权在 Google 官方页面完成。应用不会获取 Google 账户密码。drive.file 本身并非单目录或团队隔离机制；程序会另行核对配置的账户及归档目录。

2. 访问和处理哪些数据

  • 账户信息：Google Drive 返回的显示名称、邮箱、账户标识和存储配额，用于确认账户和可用空间。
  • 文件与目录信息：获得授权的目标目录和测试文件的名称、标识、父目录、所有权、共享权限、大小及内容校验值。
  • 文件内容：当前仅上传并读取程序生成的固定测试文本，不上传项目内容，也不遍历和读取你的其他 Drive 文档。
  • 连接凭据：Google OAuth 访问令牌、刷新令牌及客户端连接设置，用于建立和维持授权连接。
  • 运行记录：操作时间、检查结果、错误类别、文件标识和校验值等，用于排查问题和核实操作是否完成。正常运行回执不记录令牌或 Google 密码。

3. 数据的用途和共享

上述数据仅用于你发起的连接验证、账户与目录检查、容量检查、测试文件存取和必要的故障排查。测试文件内容及必要请求信息会通过 Google Drive API 发送给 Google。

当前归档连接组件不将 Google Drive 数据发送给模型服务，不使用这些数据训练模型，不出售数据，不用于广告、信用评估或用户画像，也不向公开 GitHub 仓库或本网站发布这些数据。

运行记录可由账户所有者及其明确授权的维护人员在必要范围内检查。除提供上述功能、经你明确授权的排错、安全保护或履行适用法律要求外，不向第三方提供 Google 用户数据。

CloudBot Archive 对从 Google API 获取的信息的使用及转移遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。若未来增加数据用途或功能，会先更新披露并取得必要授权。

4. 数据保存在哪里

测试文件保存在账户所有者选择并由程序核对的 Google Drive 目录中，沿用该目录的共享设置；当前程序不会将它改为公开共享。

连接设置、OAuth 凭据和检查记录保存在操作者控制的本地运行设备中。凭据目录使用操作系统访问权限限制访问；与 Google API 的通信使用 HTTPS。当前版本不提供对本地凭据的端到端加密或静态加密承诺。

本说明网站不会接收这些凭据、Drive 文件或运行记录。以后如果改变运行地点、保存方式或用途，会更新本政策。

5. 保留、撤销和删除

当前没有按天数自动删除的机制。测试文件、连接凭据和运行记录会保留，直到账户所有者或获授权的操作者按下列方式处理：

  1. 在 Google 账户的第三方连接页面 撤销 CloudBot Archive 的访问权限，以停止后续授权访问。
  2. 在 Google Drive 中手动删除测试文件，并在需要时清空回收站。
  3. 停止本地连接程序，由操作者删除其保存的 OAuth 凭据、连接设置和检查记录。

撤销 Google 授权不会自动删除 Drive 中已有的文件，也不会清除本地记录。当前组件没有自动撤销或删除按钮。如需协助，请使用下方邮箱联系维护者，不要发送密码、令牌或私钥。

6. 本网站和第三方服务

本网站是托管于 GitHub Pages 的公开静态说明页，没有登录表单、文件上传、广告、第三方分析脚本或本网站自行设置的追踪 Cookie。

GitHub Pages 托管服务会为安全目的记录访问者的 IP 地址。其处理方式见 GitHub 隐私声明。访问 Google 服务或使用 Google Drive 时，Google 也会依照其 隐私政策 处理相关数据。
