PRIVACY POLICY

隐私政策

说明 CloudBot Archive 如何访问、使用、保存及处理数据。

生效及更新日期：2026-11-14

适用范围

本政策适用于由 YarrowHH 维护的 CloudBot Archive 归档连接组件及本说明网站。当前仅供账户所有者自用，正在有限验收账户连接、非敏感团队资料归档及隔离下载恢复，尚未正式迁移服务器；不代表整个 CloudBot 项目或其他模型服务的隐私政策。

1. 请求哪些权限

应用仅请求 https://www.googleapis.com/auth/drive.file，用于访问通过应用获得授权的文件及应用创建的文件。不申请整个 Google Drive 的广泛访问权限，也不申请 Gmail、联系人或日历权限。

授权在 Google 官方页面完成。应用不会获取 Google 账户密码。drive.file 本身并非单目录或团队隔离机制；程序会另行核对配置的账户及归档目录。

2. 访问和处理哪些数据

  • 账户信息：Google Drive 返回的显示名称、邮箱、账户标识和存储配额，用于确认账户和可用空间。
  • 文件与目录信息：获得授权的归档目录和文件的名称、标识、父目录、所有权、共享权限、大小及内容校验值。
  • 文件内容：按已登记任务上传并回读非敏感 JSON、PDF 等有界材料，并下载到隔离目录核验。本轮使用明确标记的合成验收材料，不读取未获授权的其他 Drive 文档；06_Backups 备份上传、敏感资料及大文件续传尚未开放。
  • 连接凭据：Google OAuth 访问令牌、刷新令牌及客户端连接设置，用于建立和维持授权连接。
  • 清单与运行记录：任务、团队及项目标识，来源版本、文件标识、父目录、大小、哈希、操作时间、检查结果和错误类别，用于固定归档范围、核对重复操作及验证恢复。正常回执不记录令牌或 Google 密码。

3. 数据的用途和共享

上述数据用于你授权的连接验证、账户与目录检查、容量检查、团队资料归档、清单核验、隔离下载恢复及必要的故障排查。选定文件的内容、归档清单及必要请求信息会通过 Google Drive API 发送给 Google。

当前组件不把 OAuth 凭据或原始 Drive 文件内容发送给模型服务。幕僚长可读取获准的状态摘要和必要元数据，例如文件标识、哈希及验证结果。组件不使用这些数据训练模型，不出售数据，不用于广告、信用评估或用户画像，也不向公开 GitHub 仓库或本网站发布这些数据。

运行记录可由账户所有者及其明确授权的维护人员在必要范围内检查。除提供上述功能、经你明确授权的排错、安全保护或履行适用法律要求外，不向第三方提供 Google 用户数据。

CloudBot Archive 对从 Google API 获取的信息的使用及转移遵守 Google API Services User Data Policy，包括适用的 Limited Use 要求。若未来增加数据用途或功能，会先更新披露并取得必要授权。

4. 数据保存在哪里

归档文件和清单保存在账户所有者选定的 CloudBot 根目录下、经核验的团队分类目录中。程序不更改共享设置；目录位置、所有权或权限不匹配时停止相关操作。

连接设置、OAuth 凭据、任务登记和检查记录保存在操作者控制的本地运行设备中，下载恢复副本保存在独立的本地目录中，不自动运行恢复内容。凭据目录使用操作系统访问权限限制访问；与 Google API 的通信使用 HTTPS。当前版本不提供对本地凭据的端到端加密或静态加密承诺。

本说明网站不会接收这些凭据、Drive 文件或运行记录。当前尚未正式迁移服务器；以后如果改变运行地点、保存方式或用途，会更新本政策。

5. 保留、撤销和删除

当前没有按天数自动删除的机制。归档文件、清单、本地恢复副本、连接凭据和运行记录会保留，直到账户所有者或获授权的操作者按下列方式处理：

  1. 在 Google 账户的第三方连接页面 撤销 CloudBot Archive 的访问权限，以停止后续授权访问。
  2. 在核对保留要求后，在 Google Drive 中手动删除不再需要的归档文件或清单，并在需要时清空回收站。
  3. 停止本地连接程序，由操作者按保留要求处理本地恢复副本、OAuth 凭据、连接设置和检查记录。

撤销 Google 授权不会自动删除 Drive 中已有的文件，也不会清除本地记录。归档或恢复成功不自动授权删除源文件或旧副本。当前组件没有自动撤销或删除按钮。如需协助，请使用下方邮箱联系维护者，不要发送密码、令牌或私钥。

6. 本网站和第三方服务

本网站是托管于 GitHub Pages 的公开静态说明页，没有登录表单、文件上传、广告、第三方分析脚本或本网站自行设置的追踪 Cookie。

GitHub Pages 托管服务会为安全目的记录访问者的 IP 地址。其处理方式见 GitHub 隐私声明。访问 Google 服务或使用 Google Drive 时，Google 也会依照其 隐私政策 处理相关数据。
